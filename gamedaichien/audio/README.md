# Âm thanh Đại Chiến Tri Thức

13 âm thanh riêng cho Đại Chiến. Runtime sử dụng bản copy trong `gamedaichien/audio/`, ghim commit để không phụ thuộc đường dẫn game khác.

| File | Công dụng |
| --- | --- |
| bgm-battle.mp3 | Nhạc nền |
| heal.mp3 | Hồi máu |
| rage-intro.wav | Fanfare hùng tráng 1,44 giây: tiếng đồng nhiều lớp, hai nhịp trống trầm, âm vút stereo và đuôi vang khi nhân vật trượt vào |
| holy-sword-cast.wav | Thánh Kiếm: triệu hồi |
| holy-sword-impact.wav | Thánh Kiếm: va chạm |
| meteor-cast.wav | Vẫn Tinh: triệu hồi |
| meteor-impact.mp3 | Vẫn Tinh: 3 cú va chạm dồn dập |
| build.mp3 | Xây công trình thành công |
| button-click.mp3 | Bấm nút bằng chuột/chạm/bàn phím |
| answer-correct.mp3 | Trả lời đúng |
| cannon-fire.mp3 | Bắn loạt pháo — bản sao từ Đại Hải Trình |
| damage-hit.mp3 | Đạn trúng gây sát thương — bản sao từ Đại Hải Trình |
| victory.mp3 | Chiến thắng chung cuộc — bản sao từ Báo Thủ |

## Thiên thạch va chạm

`meteor-impact.mp3` đã ghép sẵn 3 lần va chạm tại 0,00 / 0,45 / 0,90 giây. Hai tiếng đầu rút ngắn phần vang để tách rõ từng cú; tiếng cuối giữ đuôi âm. Thời lượng tổng 4,25 giây, MP3 192 kbps. Chỉ phát file này một lần cho mỗi đợt 3 thiên thạch.

5 file còn lại giữ nguyên dữ liệu và định dạng gốc.
